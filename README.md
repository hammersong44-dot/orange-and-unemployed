## To Deploy on GitHub Pages

1. Create a new GitHub repository named `orange-and-unemployed`
2. Push this folder to the repository
3. Go to repository Settings → Pages
4. Select `main` branch as the source
5. Your site will be live at `https://yourusername.github.io/orange-and-unemployed/`

Alternatively, if you want the site at your GitHub Pages root:
- Name the repository `yourusername.github.io`
- Your site will be live at `https://yourusername.github.io/`

## Features

- **Responsive Design**: Works on mobile, tablet, and desktop
- **Dark Mode Support**: Automatically adapts to viewer's theme preference
- **Photo Galleries**: Showcase Triss's family and growth
- **Clean Typography**: Custom Fredoka and Lato fonts
- **Warm Color Palette**: Inspired by Vizsla's russet coloring

## Customization

The site is fully customizable. You can:
- Add more photos to the `images/` folder
- Update text content in the HTML files
- Modify colors in the CSS `:root` variables
- Add new sections or pages following the same structure
